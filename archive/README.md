# Archive

Original, unedited versions of the scripts now in `scripts/`, kept for
traceability. These are **not maintained** and should not be run directly:
several contain known bugs that were fixed while migrating the code (see the
main [README](../README.md) and the commit history for details).

Two kinds of files live here:

- Scripts that were cleaned up, had their paths parametrised, and were
  renamed into the numbered pipeline in `scripts/` (e.g.
  `03-ExtractVGDBPointData_v03.R` became `scripts/07_extract_vgdb_point_data.R`).
- Superseded versions of a script that a newer version replaced (e.g.
  `03-ExtractVGDBPointData_v02.R`, superseded by `_v03`).
